# libGDX UI Harness 2.0.2 candidate

This patch corrects two layout-validation false failures found while integrating a game menu,
pause/settings screens and a gameplay HUD.

- `INTERACTIVE_OVERLAP` ignores effectively invisible controls, including buttons below a hidden
  ancestor. Showing those controls still exposes real overlap failures.
- Owned TextButton/CheckBox label geometry uses the same visible-text whitespace normalization as
  semantic snapshots. A label such as `Esc   Pause` retains intrinsic text evidence. A semantic
  override with different content still produces `CHECK_UNAVAILABLE`; no descendant-text guessing
  or fallback bounds are introduced.

The public APIs, result schemas and tool catalog are unchanged. Actor access remains confined to
the render thread. The existing input/text/tree limits still apply, and the shared normalizer is
package-private. No game visual approval or broader platform qualification is implied.

The six coordinates remain `harness-core`, `harness-scene2d`, `harness-lwjgl3`, `harness-protocol`,
`harness-mcp` and `harness-agent-runtime` under `io.github.teemuki8`. Align all six on 2.0.2 after
publication. Fixtures and benchmarks are not published.

This is a local candidate, not a publication receipt. The signed-tag workflow, Central
`PUBLISHED` state and public coordinate verification remain required before consumers upgrade.
