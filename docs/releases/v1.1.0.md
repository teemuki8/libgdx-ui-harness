# libGDX UI Harness 1.1.0

## Highlights

- evaluator-complete state/action contracts and versioned diagnostics;
- inspect, capture, compare, typography, HiDPI, layout, clipping, and viewport
  diagnostics;
- independent structural-usability and joined trace/failure evidence;
- bounded convergence, recovery, and cost policies;
- a digest-bound, all-runs repeatability release gate;
- Apache 2.0 license text embedded in every published main, source, and
  Javadoc JAR;
- strict locator suggestions on zero and multiple matches from retained
  evidence with configurable redaction;
- deterministic navigation inspect and validate operations over real input
  dispatch with classified terminal reasons;
- whole-stage layout invariant validation from one completed frame with closed
  reason codes and a severity-gated CI status;
- bounded display-matrix execution with distinct case statuses and compact
  retained reports;
- versioned semantic golden comparison without raster capture and explicit
  ambiguity on duplicate identities;
- compact state-transition queries over retained bounded traces with explicit
  gaps, unknown causes, and identity ambiguity;
- explicit UI-to-runtime entity and property bindings with typed
  frame-correlated comparison;
- the ADR 0025 runtime-binding SPI is realized by a publishable
  `harness-agent-runtime` module that reads bound values from a live
  `AgentRuntime` with strict frame correlation.

## Compatibility

This release adds public contracts while preserving the 1.0.0 binary and source
API. Published modules still require Java 25.
