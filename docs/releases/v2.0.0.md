# libGDX UI Harness 2.0.0

## Highlights

- adds bounded intrinsic Scene2D `Label` geometry for clipped-text and visible glyph-ink collision diagnostics using the real Stage viewport, Actor transforms, and ancestor `ScrollPane` actor-area clips;
- accepts signed layout-finding positions while retaining finite, non-negative finding dimensions;
- makes requested checks with unavailable navigation, cohort, clip, or exact text evidence fail with error-severity `CHECK_UNAVAILABLE` instead of silently passing;
- removes structural false positives by making obscuration opt-in and ancestry-aware, restricting target-size checks to canonical interactive roles, and requiring explicit same-parent `layout-group` plus `layout-axis` metadata for alignment and spacing; and
- keeps every evidence set immutable and bounded, including hard unavailability when an exact libGDX wrap/ellipsis placement or complete clip chain cannot be proven.

## Major-version compatibility

This is a major release because the same validation request can produce a different qualification result. The default check set now includes `text-collision`, requested unavailable checks are hard errors, obscuration is no longer a default check, and alignment or spacing without an explicit qualifying cohort reports unavailable rather than inferring siblings. Consumers that treated a previous `PASS` as proof despite missing evidence must update their qualification expectations.

The public tool remains `ui_validate_layout`; its protocol version and result shape are unchanged. Existing three-argument core `LayoutValidator.validate` callers remain source-compatible, but requested intrinsic checks report unavailable because that overload cannot supply text geometry. Scene2D sessions use the evidence-backed overload automatically. The closed request and reason enums add `text-collision` and `TEXT_COLLISION`, so clients with exhaustive enum handling must accept the new values.

## Migration

- Use a Scene2D-backed session when requesting `clipped-text` or `text-collision`; toolkit-neutral callers must provide `LayoutValidationEvidence` explicitly.
- Add nonblank `layout-group` and `layout-axis=horizontal|vertical` semantic properties to peers that should be checked for alignment or spacing, or disable those checks when no objective cohort exists.
- Request `obscured` explicitly when higher-z sibling overlap is part of the qualification contract.
- Treat `CHECK_UNAVAILABLE` as a failed requested check, including when bounded finding output truncates the corresponding diagnostic.
- Continue to resolve `relatedActorId` as a snapshot node identity; cohort names remain bounded textual evidence.

All Stage, Actor, font, transform, and clip reads remain render-thread confined. Evidence maps, clip chains, strings, findings, and output schemas retain hard bounds. Ambiguous private libGDX state is never inspected through reflection or side-effecting draw capture. The harness remains style-neutral and does not generate visual designs or approve subjective presentation.
