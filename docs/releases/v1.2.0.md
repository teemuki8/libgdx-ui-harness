# libGDX UI Harness 1.2.0

## Highlights

- bounds JSON-RPC stdio frames before deserialization, rejects excessive nesting and malformed UTF-8 with typed errors, and keeps the server available after rejected frames;
- replaces backtracking regular-expression matching with bounded linear-time evaluation;
- bounds request admission, serializes mutating MCP operations, removes the scheduler cancellation/drain lock inversion, and enforces deadlines even when no frame completes;
- enforces Scene2D session ownership on the render thread and preserves first-wins lifecycle cleanup across cancellation, deadline, close, and submission-failure races;
- suppresses completed-frame snapshots when no scenario or navigation runner is active;
- carries screenshot captures as bounded immutable binary attachments inside the protocol execution path, removing the internal base64 encode/decode round trip while preserving the versioned JSON wire format;
- adds digest-bound semantic baselines, explicit runtime value formatting, independent fixture UI/runtime state, and deterministic matrix case application so semantic comparisons cannot pass on stale or self-derived values;
- binds finalized traces to event, artifact, archive-size, and SHA-256 evidence; bounds decompression and archive reads; verifies publisher receipts against the exact captured bytes; and retains bounded recovery accounting with redacted publication failures;
- hardens trace finalization and cleanup against symlink, pathname-replacement, inode-reuse, and stale-receipt races while leaving unproven replacement content untouched;
- synchronizes the agent-tools guide with the executable MCP schemas and adds a parity test that rejects future required-input drift.

## Compatibility

- The six published modules remain source- and binary-compatible with 1.1.0 for supported APIs. Version 1.2.0 adds public contracts and result fields without intentionally removing a 1.1.0 API.
- Regex locators now use RE2/J. Backreferences, lookahead and lookbehind, atomic or possessive groups, conditionals, and other backtracking-dependent constructs are no longer supported and fail with `invalid-request`.
- The project continues to require Java 25 and targets LWJGL3 desktop with Scene2D/Scene2D.UI.
- Trace recording continues to fail closed on file-system providers that cannot supply `SecureDirectoryStream`; other harness features remain available.
- Protocol data remains versioned as `v1`. Newly emitted fields are additive, bounded, and serializable.
