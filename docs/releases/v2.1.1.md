# libGDX UI Harness 2.1.1

Corrects editable text-field inspection and empty-state action responses used by normal markup
forms and authoring tools.

Standard Scene2D TextField geometry is derived from public state on the render thread without
calling draw or mutating the control. Intrinsic text containment and collision diagnostics
account for the field's visible text range, scrolling, alignment, font metrics and placeholder
state. Unsupported custom or multiline geometry is explicitly unavailable rather than guessed.
See ADR 0042 for the supported boundary.

Clearing a field through production input can now return a successful action response whose
`observedState` is the empty string. Protocol serialization, MCP schema diagnostics and the tool
catalog agree on that valid observation. Other string bounds, locator validation and request
schemas retain their existing contracts. See ADR 0043 for the field-specific change.

## Compatibility and coordinates

Align `harness-core`, `harness-scene2d`, `harness-lwjgl3`, `harness-protocol`, `harness-mcp` and
`harness-agent-runtime` on **2.1.1** under `io.github.teemuki8`. No new tool or application input
path is introduced. Java 25, libGDX and existing public API signatures remain unchanged;
consumers should accept corrected layout findings and empty successful observations.
Fixtures and benchmarks remain unpublished.
