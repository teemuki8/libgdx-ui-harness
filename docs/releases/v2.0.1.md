# libGDX UI Harness 2.0.1

This patch repairs incomplete layout evidence handling within the 2.0.0 contract.
Truncated evaluation cannot report PASS: it reports INCOMPLETE unless an observed failure
already establishes FAIL. Visible nonempty text without intrinsic geometry produces a located
CHECK_UNAVAILABLE finding. TextButton and CheckBox label ink remains attributable when their
owned labels are suppressed from the semantic tree.

The public result schemas and tool catalog are unchanged. Stage and Actor access remains
render-thread confined; diagnostics and geometry remain bounded. No subjective art-quality
approval is implied. See [ADR 0039](../adr/0039-complete-layout-coverage.md).

The six published coordinates remain harness-core, harness-scene2d, harness-lwjgl3,
harness-protocol, harness-mcp, and harness-agent-runtime under io.github.teemuki8.
Fixtures and benchmarks are not published. Align harness modules on 2.0.1 when available.

Publication is complete only after the signed-tag workflow reports PUBLISHED and all public
coordinates resolve. This candidate note is not a publication receipt.
